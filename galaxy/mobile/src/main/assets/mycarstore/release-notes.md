# 0.1.152 更新内容

- 修复音乐跑调、降调问题：移除音乐播放速率补偿，保持音源采样率播放，保留短时欠载缓冲恢复。
- 改进 USB 启动恢复、多手机配对和无线取消、重连时的资源清理。
- 接入 L7／L6 原生媒体方控，优化按键发送队列与重复输入处理；补充接入、注册、按键和释放阶段日志，便于定位失效。
- 新增手动性能监控，分别显示 UFPS（应用界面帧率）与 CFPS（CarPlay 投屏帧率）；未投屏、静止和等待数据均有明确提示。
- 优化日志采集与窗口刷新，监控关闭时停止采样，深度诊断限时运行。
- Wi-Fi Direct IP 模式可随配置保存；新增 L7 有／无头枕预设，两份预设均默认首选 C2、60 fps、80% 清晰度，硬件不可用时保留回退。
- 配置支持精简二维码、复制文本、文字粘贴预览导入及文件导出；保存时填写配置名称，分享备注独立填写，中英文默认名称随语言显示。
- 偏好设置新增“连接”分类，集中设置 Wi-Fi Direct IP 模式。

以上汇总自线上 0.1.142 之后的更新。实际方控、头枕音频、无线稳定性和高帧率效果仍需按车型及固件验证。
