# 0.1.140 更新内容

- Wi-Fi Direct 等待手机接入时，五秒后尝试本轮已监听且仍有效的另一种 IP 地址，改善部分车机的连接兼容性。
- 接入后继续沿用实际会话地址；补发保持当前网络、密码、端口和认证身份，收到连接或取消后停止补发。
- Direct 仍采用有限等待和重试，具体连接效果需实车验证。

包含 0.1.139 的音频缓冲选项：

- 音乐缓冲新增「跟随手机协商」，按每次连接、每条音频流提供的有效目标播放。
- 电话、Siri、导航分别开放播放缓冲：默认策略、跟随手机协商，以及 32、80、160、300、500 ms。
- 音乐手动缓冲按所选档位执行，不再因历史网络抖动自动提高启动水位。
- 各用途独立保存，修改确认后需在偏好页保存，下次连接生效；当前连接继续使用原设置。

增大缓冲会增加声音延迟，电话和 Siri 建议保留默认策略。手机未提供有效协商值时使用默认值；具体延迟与听感仍需实车验证。包含 0.1.138 的无线连接有限恢复。
