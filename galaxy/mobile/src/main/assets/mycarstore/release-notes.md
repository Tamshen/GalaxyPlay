# 0.1.145 更新内容

- 新增手动性能检测，默认关闭；左上角紧凑显示 CPU、内存和投屏呈现 FPS，整个面板触控透传，无权限时可在应用内查看。
- 基础检测低频采样并沿原日志记录摘要；深度线程采样需另外手动开启，15 秒后自动结束。停止检测会清理窗口和采样任务。
- 已选 L7／L6 且启用方控时尝试订阅 Android 原生媒体键，首次按下派发，过滤按住及跨入口副本；服务不可用时保留标准通道。
- 媒体发送使用独立有界顺序队列，减少触控任务排队影响，保留手机会话隔离和蓝牙媒体保护。
- 减少日志重复脱敏和文件打开，后台有界批量写入；保留事件时间、配置上下文、轮转和清空语义，日志窗折叠／暂停时减少无效快照。

保留有线恢复、多手机配对及音乐原采样率播放修复。原生方控权限、物理按键响应和检测开销、长期 CPU／音视频表现仍需按车型实车验证。
