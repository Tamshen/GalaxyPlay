# 0.1.148 更新内容

- 偏好设置中的“重置、分享、导入”合并为同一行三个等宽按钮，减少顶部占用。
- L7 预设分为“L7(带头枕)”和“L7(无头枕)”，两套均为 60 fps、80% 清晰度；带头枕关闭音频焦点，无头枕开启，其余参数一致。
- 车型常用设置新增 Wi-Fi Direct IP 模式：仅 IPv4、仅 IPv6、IPv4 + IPv6，默认仅 IPv4；保存后下次连接生效。
- 配置支持备注名称，默认“配置01”等顺序名称；可生成二维码、复制配置文本或保存专用配置文件，方便拍照和分享。
- 接收方在车机粘贴配置文本，预览名称与关键参数并确认后应用；导入只替换车型配置，保留热点、认证、应用设置和正在运行的会话。

保留 L7 大陆地区 149 信道、45 秒连接等待及出画面后的蓝牙控制回退。已有配置不自动覆盖；可明确选择新预设使用默认参数。新模式、60 fps 与长期声音表现仍需实车复验。
