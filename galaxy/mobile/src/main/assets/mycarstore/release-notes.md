# 0.1.134 更新内容

- 日志上传改为完整分批上传当前保留的本地日志和轮转历史，不再按 1 MiB 总量或 5000 条省略上下文。
- 单批最多 256 KiB／1000 条，按顺序发送并显示进度；失败后手动重试继续原快照，跳过已确认批次。
- 完整快照暂存应用私有缓存，发送时只读取当前批，避免大量日志占满内存；成功或停止后自动清理临时快照。
- 保留同事件副本合并、独立重复故障、历史配置关联和脱敏，上传期间新增日志在下一次上传纳入。
- 本地日志总量超过 5 MB 时自动清理较旧记录，保留最近上下文。
- 启动及运行期间自动清理闲置上传快照、封面及更新临时文件，保护活动任务；上传临时存储设有限额，超额明确失败而不丢弃日志。
- 应用设置新增数据、日志、缓存、其他数据及当前运行内存占用，后台统计，离开页面停止更新。
