# 0.1.131 更新内容

- Wi-Fi Direct 补齐同一 P2P 接口的 IPv4／IPv6 服务发现和 AirPlay TCP 监听，避免接口已有 IPv6 却只发布 IPv4。
- 无线音乐解码器输入暂时不足时先排出输出并有限等待，保留原包，减少突发到包和 CPU 调度延迟时的丢音。
- 修正音乐欠载后的恢复：有压缩包等待时也能重新预缓冲，保留已有 PCM；按观测到的网络间隔调整当前会话水位，受原车实际容量限制。
- 复用音频解码输出信息对象，继续保留上一版日志减量和低频 CPU 记录。

电话、导航与 Siri 保持原低延迟处理；实际车机连续播放和 iPhone Wi-Fi Direct 连接效果需复验。
