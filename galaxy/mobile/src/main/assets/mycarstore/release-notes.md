# 0.1.144 更新内容

- 有线配对、网络接入和状态回调绑定当前连接；取消、拔插和快速重连后的旧任务不会保存配对或解绑新连接。
- NCM 数据写入从暂时不可写恢复后，尚未建立控制连接时最多补发三次有线启动请求，沿用原端点和超时期限。
- 按每部手机的公钥分别保存及校验配对记录；匹配时迁移旧记录，单手机重新配对保留其他手机记录。
- 配对保存确认持久化结果，失败时明确结束当前尝试，避免重启后丢失记录却显示保存成功。
- 有线连接关闭时逐项清理资源；关闭异常仍继续其余清理，后台线程未退出时阻止再次连接。

包含 0.1.143 的音乐原采样率播放修复，不再启用音乐升降调补偿。真实 USB 启动、首帧、拔插重连和两部 iPhone 交替连接仍需实车复验。
