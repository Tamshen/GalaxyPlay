# 0.1.142 更新内容

- Wi-Fi Direct 增加 Android 11 后台扫描暂停，减少搜索网络造成的音画停顿；需要已授权的本地 ADB，断开后恢复，可在无线连接设置中关闭。
- 无线投屏增加 Wi-Fi 高性能与低延迟锁，断开后释放；提供独立开关，下次连接生效。
- 提高音视频接收、解码、播放和麦克风线程优先级，改善车机忙碌时的调度。
- 音乐增加有界时钟漂移补偿与持续积压清理，保留短暂无线突发；电话、Siri 和导航不使用音乐调速。
- 原生热点优先使用现有读取接口；失败后，在 Android 11 上通过已授权本地 ADB 尝试读取名称和密码，不申请新授权、不改写系统热点配置。

保留 Direct 地址恢复、分用途音频缓冲及现有车型音频路由。实际无线建链、长期音频稳定性与听感仍需实车验证。
