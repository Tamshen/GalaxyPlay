# 0.1.135 更新内容

- Wi-Fi Direct 增加使用地区设置，默认中国大陆车载；其他地区使用独立的 2.4 GHz 保守候选，不把亚洲视为同一频段规则。
- 中国大陆车载自动优先 149 等高 5 GHz 信道，系统拒绝后在允许的候选内有限回退；保留共享射频同信道和 2.4 GHz 共存处理。
- 中国大陆车载不再自动或手动选择 36–48 室内专用信道；实际建组回读也核对地区限制，异常组在广播和发送配置前停止并清理。
- 保留原有手动频道；不适用于所选地区时明确提示重新选择，不静默覆盖或强改系统国家码。无法固定地区允许频道的系统给出失败提示。
- 中英文同步显示地区、频道选择和失败恢复路径；已有原生热点、完整日志上传及存储管理保持兼容。

Wi-Fi Direct 自动密码弹框与首次接入效果仍需实车复验，软件信道调整不代表已经确认其根因。
