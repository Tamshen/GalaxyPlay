# 0.1.164 更新内容

- 新增“调试 → 环境检测 → CarPlay 环境测试”，一次采集 USB连接验证测试 相关环境、权限及候选依赖，并观察 20 秒插拔变化。
- 检测结果进入现有报告和日志，停止或中断保留部分结果，完成后可主动上传。
- USB 模式切换失败后停止自动重试，保留明确提示和手动重新连接入口，避免反复申请授权。
- 有线连接增加分阶段提示和“USB 连接排查”入口，补齐模式请求耗时、授权来源、插拔事件与有界能力查询日志。

环境测试不切换 USB 角色或写入系统配置；权限不足与未发现分别记录。采集完成不代表 CarPlay 参考应用 已可用，USB 实际接通仍需结合实车报告验证。
