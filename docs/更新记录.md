# 产品变更

产品版本以 [版本配置](../gradle/galaxyplay-version.properties) 为准，验证状态见 [开发说明](开发与验证.md#验证与验收)。仅记录用户可感知的功能，不保存开发讨论、原始日志或排查过程。

## 0.1.168（2026-10-20）

- 程序外悬浮图标单击直接返回 CarPlay 画面，无连接时返回首页；保留拖动、透明度与前台隐藏，应用内菜单保持原有操作。

## 0.1.167（2026-10-20）

- 有线连接新增“USB连接验证测试”，默认关闭，尝试使用车机已有的 USB 网络与 iAP 通道接入现有 CarPlay 会话。
- 连接前检查控制接口、固件配置规则和设备节点权限；记录角色请求、配置回读、握手、网络、首个连接与恢复结果，失败显示原因码并停止自动重试。
- 保存切换前的原配置，结束时恢复；未确认恢复时保留记录和“恢复 USB 原配置”入口。
- 本版为实验接入，厂商 APVP 控制未移植；固件依赖与实车连接效果仍需分别验证。

## 0.1.166（2026-10-19）

- 增加首次无线连接与重试的诊断锚点，关联认证、Wi-Fi 配置、启动请求、首个 TCP、会话建立及超时快照。
- 补充广播配置前后回读、服务发布状态、站点授权和 IPv4 邻居计数；采样有次数与时间上限，读取失败不影响连接，不把配置回读当作手机收到广播或 DHCP 成功。

## 0.1.165（2026-10-19）

- 无线连接区分 Wi-Fi Direct 系统忙、拒绝清理、清理超时与旧连接未释放，连接页显示具体原因和恢复步骤。
- 此类失败停止自动重试，保留手动恢复和重新连接入口；日志保留系统返回码与分类原因，迟到回调不覆盖提示。

## 0.1.164（2026-10-19）

- 新增“调试 → 环境检测 → CarPlay 环境测试”，一次采集 USB连接验证测试 所需环境与候选依赖，并观察 20 秒插拔变化。
- 逐项保存来源、可见性、访问条件、耗时和未验证边界；停止或中断保留部分报告，结果进入现有日志，由用户主动上传。
- 采证期间阻止本应用自动启动连接；不切换 USB 角色、不写系统配置，不把环境可见或端口可达当作 CarPlay 可用。

## 0.1.163（2026-10-19）

- 有线连接按实际阶段提示授权、保持解锁、重新识别及手机确认；新增“USB 连接排查”入口，说明旧 CarPlay 记录检查和单次日志反馈方法。
- USB 日志增加模式请求耗时、授权结果来源、插拔事件和手动排查操作；切换失败后补充一次有界能力查询，便于区分失败阶段，不自动改变 USB 主从角色。

## 0.1.162（2026-10-19）

- USB 切换 CarPlay 模式失败后停止自动重试，保留明确原因与“重新连接”入口；设备断开再出现不会继续循环申请授权。
- 提示解锁 iPhone、允许 CarPlay 后手动重试；此版本修正失败恢复流程，模式切换兼容性仍待实车验证。

## 0.1.161（2026-10-19）

- USB 切换 CarPlay 模式失败时补充有界配置描述符与模式查询结果，兼容三字节响应；查询和日志异常保留原始失败原因，便于上传报告后进一步定位。

## 0.1.160（2026-10-19）

- Direct 暂停后台扫描在本地 ADB 不可用时，尝试使用 Android 11 车机已有的本机维护通道；保持会话内暂停，退出后恢复，并记录实际执行通道与失败原因。
- 导航结束后音乐焦点请求失败时增加一次有限恢复，支持系统延迟授予；新导航、暂停、失焦或退出会取消待执行恢复。
- 无线缺包与音乐听感改善仍需实车复验。

## 0.1.159（2026-10-19）

- 补齐系统底栏的歌曲封面读取授权，切歌时更新当前封面的授权；显示效果待实车验证。

## 0.1.158（2026-10-19）

- 补齐 Direct 播放期间的扫描、接收缺包和音频重新缓冲日志，修复长断流等待计时与性能日志 CPU 字段误脱敏，方便上传后定位卡顿。

- Wi-Fi Direct 首次 TCP 接入等待由 45 秒缩短至 30 秒，保留五秒补发；失败后更早进入有限重试。

- 媒体诊断补充注册、选源、播放权、焦点和仪表媒体服务状态摘要；支持按中控／仪表记录歌名、封面、播放状态与进度的实际显示结果，并关联当前会话保存到日志。
- 偏好设置的原车音乐与媒体上报改为单一开关，默认开启；关闭后不注册。移除网易云、QQ 和本地音乐渠道，旧渠道值不再影响注册，保存后重新连接生效。

## 0.1.157（2026-10-19）

- Wi-Fi Direct 自动加入准备统一供 L6／L7 共用，不再依赖车型识别或配置模板。

## 0.1.156（2026-10-19）

- 为 Android 11 Wi-Fi Direct 补充 Apple Auto-Join 广播准备，连接时独立完成并核验，重复连接不重复追加。
- 自动加入准备失败时给出明确提示；取消和重连隔离旧会话，保留其他应用的无线广播元素。

## 0.1.155（2026-10-18）

- 修复原车选源确认回调反复申请播放权的问题，重复选中当前来源时保留已上报的歌曲和封面。
- 重复收到同一封面时保留已有图片与读取地址，避免反复写入和刷新；封面内容变化及重新连接仍正常更新。
- 导航信息上报切换为高德标准广播，发送手机实际提供的路名、转向、距离、剩余时间和到达时间文本，结束、过期和断开时清理；移除原 Ecarx 导航服务发布路径。
- HUD 调试增加左右转、距离和剩余时间样例，支持完整重发；广播发送结果与实车显示结果分别记录。

## 0.1.154（2026-10-18）

- 连接手机后，将 GalaxyPlay 的名称、图标和媒体来源登记到原车媒体目录；已有本应用条目更新自身字段，保留其他音乐应用。
- 音乐上报渠道切换时补充对应目录来源，保留原有来源；目录不支持或登记未确认时继续现有歌曲上报，并记录具体阶段结果。

## 0.1.115（2026-10-10）

- 补齐原车音乐卡片的应用图标、点击返回 GalaxyPlay 和真实能力字段；切歌／清理失效旧快照，服务恢复隔离旧控制与焦点回调，注册异常有限重试。
- 显式应用 L7 快速模板时按原厂角色保存导航／铃声的可降音短时焦点；旧配置和已保存音频方案保持原样，连接／应用／认证设置独立保留。铃声内容属性修正为提示音。
- 不复制原厂 SDK 实现；Android VM 契约替身测试仅进入测试 APK。两车型原车显示、手机实际响应、物理声音及完整 HUD 字段仍沿原任务验收。
