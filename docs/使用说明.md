# 使用说明

[项目入口](../README.md) · [开发与验证](开发与验证.md)

项目与应用名称统一为 GalaxyPlay，桌面和系统应用管理显示同名。

## 安装与首次启动

仅面向吉利银河 L7，最低 Android 10，目标环境为 Flyme OS / Android 11、1440×1920 竖屏。应用包名为 `com.ecarx.carplay`。覆盖安装需要签名一致、版本码符合系统要求；同名原厂应用不一定能被本项目覆盖。

首次使用或协议正文变更后，必须滚动至文末、在前台等待至少 5 秒，再主动勾选并同意。计时未完成时转到后台，返回后重新计时。拒绝则退出；未同意时不启动连接。设置 → 关于 → 使用协议可查看或撤回；撤回停止会话和服务、清除同意记录，保留连接配置。

麦克风、蓝牙及连接相关权限按用途申请。系统悬浮权限用于桌面菜单和可选调试日志，不是 CarPlay 连接条件。从系统设置返回后，以应用重新查询的权限结果为准。

## 连接

| 方式 | 操作 |
| --- | --- |
| 无线 | 在 Android 原生设置开启热点；应用连接设置会尝试读取名称、密码，也可手动填写。选择手机、完成蓝牙授权后启动无线连接 |
| USB 有线 | 使用支持数据传输的线连接 iPhone，在首页选择有线连接，并处理设备授权 |
| 立即连接 | 完成配置后显示，沿用上次连接方式；已有任务时查看进度或返回 CarPlay，不重复建会话 |
| 重新连接当前连接 | 设置 → 连接设置的第三项；沿用当前会话的无线或 USB 方式，释放旧会话后重新连接。无可重连会话时禁用，处理期间不能重复提交 |

画面异常但音频仍正常时，视频失败提示提供「重试画面」：保留连接和现有音频，只尝试恢复视频。提示显示已请求后仍需等待实际新画面，不能据此认定恢复成功；仍未恢复时，点击「返回连接设置」，再选择「重新连接当前连接」。HEVC 失败时也可按提示选择 H.264 后重新连接。

无线 CarPlay 使用 **Android 原生设置 → 网络和互联网 → 热点与网络共享**，与车机桌面自带的热点服务不同。连接设置先选择「无线连接」或「有线连接」，分别进入引导；首页两个入口也直接打开对应引导。仅无线页读取现有热点配置，读取失败保留已保存值，并提示手动核对。页面保留独立「原生 Wi-Fi 设置」入口，沿用热点功能调整前的实现：查询原有热点 action，无可用入口时打开无线网络设置。读取与写入权限不同，读不到名称/密码不代表热点未开启，不阻止生成并应用新配置。

无线连接先在顶部确认车机蓝牙已开启、应用可读取配对且所选 iPhone 仍在已配对列表；不要求 A2DP 媒体连接。未通过时点击连接会先显示原因，不执行热点预检。随后无线引导分为三步：①开启 Android 原生热点；②读取或手动填写并核对名称、密码；③在 iPhone 上加入该热点，保持 Wi-Fi/蓝牙开启，选择已配对手机并点击「无线连接」。最后一步会先读取原生热点配置，未开启时尝试开启，确认开启后继续 CarPlay 连接；已开启则直接复用。连接设置中的「一键开启原生热点」也可单独执行这一步；首次可能需要允许修改系统设置，返回后再次点击。需要新配置时选择「生成 CarPlay 热点配置」：名称为 `CarPlay_` 加匿名设备编号 MD5 后四位，密码独立随机生成 16 位大小写字母与数字，使用 WPA2。确认「应用并开启」才尝试写入，系统接受后才保存到应用；已开启的热点不重配。固件拒绝配置写入时，可以重新打开生成窗口，复制同一份名称、密码到原生设置。修改系统设置授权不保证具备热点配置权限，应用会明确显示失败原因。显式开启、读取、应用配置使用进度弹窗，失败保留结果和授权/原生设置入口，关闭才消失；「配置已保存」与「热点已开启」分别确认，超时或无法查询不报成功。进入页面的自动读取仅更新就地反馈。

有线引导独立检查 USB Host 声明、Apple USB 设备枚举和访问权限，不读取或开启热点、不检查蓝牙。三步为：①用数据线接入车机数据口；②开始连接后允许 Android 的 USB 访问提示；③保持 iPhone 解锁并允许 CarPlay。重新检测只读状态，不申请权限或发指令；无设备时明确确认才进入等待，不支持或检查异常时显示结果和重检入口。设备识别、USB 授权均不等于 CarPlay 已连接。

有线连接所需的网络授权页缺失或系统拒绝时，失败弹窗提供 ADB 操作提示。已有用户反馈可通过以下命令授权；本车机固件上的效果仍待测试。先将电脑 ADB 连接到车机，再执行：

```sh
adb shell appops set com.ecarx.carplay ACTIVATE_VPN allow
adb shell appops get com.ecarx.carplay ACTIVATE_VPN
```

检查结果为 `allow` 后返回应用点击「重新检查并授权」，继续验证 USB 连接。`ACTIVATE_VPN` 是 AppOps 项；应用已声明 `CONTROL_VPN` 控制候选权限并保留 VPN 服务的 `BIND_VPN_SERVICE` 保护，但权限声明不等于获授，也不能替代这条 AppOps 授权。

有线连接还需系统网络授权。授权页面不可用、系统拒绝、调用失败或用户拒绝／取消时，应用显示原因并停止本次启动，可重新检查并授权、返回有线设置或查看日志。手动连接异常结束后，重开应用也可看到上次连接未正常结束的提示；最近两次尝试的阶段、异常摘要和可用退出原因会随您主动查看、上传或导出诊断提供，无需开启自动连接或悬浮日志。只有未知退出证据时不直接判断为崩溃。

开启自动连接后，若连续 3 次启动或连接异常退出，下次启动会自动关闭自动连接并提示，保留认证、热点与配对配置。仍可查看日志、修改设置或手动连接；排查后可在通用设置重新开启。

手动填写名称和密码仅保存应用连接信息，不修改系统热点。离开设置会取消等待，已提交的系统操作可能继续完成；应用不会关闭热点。等待页的返回保留连接任务，取消结束本次任务。切换设置、返回桌面或关闭悬浮日志不会断开连接。

HEVC 尚未完成实车验收，默认使用 H.264 / 30 fps。出现黑屏但有声音时，在显示设置关闭 HEVC 后重新连接，并导出对应时段诊断；有声音不能证明视频解码成功。

## 菜单与设置

一级菜单只有画面、设置、车机、退出。首页和连接成功后默认收起为可拖动图标；点击图标或投屏页返回键，在左上角固定位置展开。点击画面或菜单外收起，不改变投屏画布。iPhone 会话连接后，「画面」显示绿色圆点并以绿色强调，断开后恢复；设置和桌面菜单同步显示，当前页面选中底色独立保留，页面底部不再显示连接状态。绿色表示会话已连接，不代表视频首帧已显示。退出需确认，随后停止连接及服务并结束应用进程。

设置包含车型、认证、连接、显示、音频、通用、权限、调试、日志、关于十类。「车型设置」是首页第一项，进入独立页面选择车型或复查识别结果。「调试」与「日志」分别为独立入口；调试子页返回调试首页，调试与日志分类均返回设置。无线/有线引导先返回连接方式，再返回设置首页；其他分类子页返回设置首页，再次点击侧栏设置始终回到分类首页；从画面返回设置可恢复原子页。选择器确认才保存，取消或系统返回保留旧值；需重建会话的参数下次连接生效。

| 常用功能 | 位置与说明 |
| --- | --- |
| 界面大小 | 显示 → 应用界面；小 240、中 280（默认）、大 320 DPI，或自定义 160～480；只调整应用 UI，不改系统密度和投屏参数 |
| 悬浮入口 | 显示 → 悬浮菜单；调整透明度、桌面悬浮菜单开关，位置可拖动保存 |
| 桌面快速返回 | 同意协议且授予悬浮权限后启用；退到桌面显示同套菜单，画面返回已有会话或首页，不自动连接 |
| 投屏参数 | 显示 → 投屏画面；全屏、编码与帧率等按实际设备能力设置 |
| 自动连接 | 通用设置；仍受首次使用协议与权限检查约束 |
| 应用语言 | 通用 → 应用语言；保留简体中文、English 和跟随系统，升级后已移除的语言选择回到跟随系统 |
| 清空所有配置 | 关于 → 应用重置；确认后删除配置、应用配对、导入认证、日志和报告，并由 Android 撤销运行时授权。应用关闭后重新打开，完成首次使用协议与授权；已安装 APK、内置认证、系统热点 / 蓝牙配对、已导出文件和服务器日志保留 |
| 开源项目 | 关于；DiPlay 与吉利二改参考分别列出版本，点击项目以模态框显示 URL、说明及打开链接按钮；第三方许可单独离线阅读 |
| 调试 | 设置 → 调试；基础环境检查、方控调试、语音输入测试、硬件解码测试与历史报告，实际调试证据默认进入日志队列并落盘 |
| 日志 | 设置 → 日志；查看、上传、清空日志或展示报告，导出、悬浮日志及服务器配置。上传时间与条数保留，进度、停止和失败重试在任务弹窗内 |

## 音频与蓝牙

首次启动识别到车型时，会提示再次确认；确认后选用对应音频方案，也可保留当前车型。已审阅的结果不反复提示。设置首页第一项「车型设置」提供 L7、L6、自定义三项选择，并显示实际适配配置；确认 L7 或 L6 后自动填入对应默认方案，未能识别时手动选择。自定义车型使用独立文件，首次按系统默认用途初始化，在音频页编辑或导入。银河 L7 提供「L7 配置」「L7 BUS」「自定义模板」；银河 L6 提供「L6 配置」「自定义模板」，采用已确认的原厂音频用途与焦点，播放位置由车机安排。内置方案只显示当前方案、简短说明及缓冲、焦点、通话音效和蓝牙等日常设置，隐藏用途编号、音道、试听、BUS 地址和文件编辑细节。L7 配置默认按标准用途交给系统；L7 BUS 显式尝试固件中的逻辑输出地址，不可用时回退系统，不能据此认定进入头枕。

自定义模板提供配置文件编辑、导入、导出及音乐／导航／Siri 的独立试听。支持默认策略组、原厂用途与传统流 1–20；usage、传统流和设备 ID 是不同编号，不代表固定扬声器位置。导入 JSON 需通过校验并确认，最多 16 KiB，失败保留原文件；编辑与选择取消不保存。三项车型分别保存自定义文件；重新选择 L7／L6 自动使用对应默认适配，原自定义文件保留，可在音频页重新选用。自定义车型的系统默认／自定义模板切换或恢复默认同样保留文件；所有保存从下次连接生效，当前会话继续使用连接时的模板。

L7 请开启原车“驾享”模式，分别验证导航、Siri 和通话是否由头枕发声。音乐避让沿用博越焦点逻辑，关闭“音频焦点”会影响全部音频；车机自身仍可能执行混音和降音策略，不承诺切换某个编号即可启用头枕。

音频焦点默认开启，模板按音频用途映射。电话优先于 Siri / 铃声，随后是导航与媒体；导航播报时降低音乐音量，结束后恢复。永久失焦后等待明确播放再申请，避免争抢。默认选择 L7 配置，自定义模板可单独开启 BUS 输出尝试。原厂用途和有线 / 无线输入源保留固件读取与回退；标准 usage 选项不被厂商用途覆盖。

先选策略，再点击两秒试听，必要时立即停止；试听不保存，确认后才保存，取消保留旧值。修改在下次连接生效。输出设备信息和播放调用成功不等于实车已发声，需分别确认音乐、导航、Siri 与通话。

音频 → 播放与焦点提供「通话回声消除与降噪」，默认开启，仅通话录音使用系统支持的 AEC/NS，Siri 录音不启用该处理。若升级后通话回声、音量或路由变差，可关闭后重新连接对比。原车处于通话、响铃或通信模式时不主动覆盖其模式。

蓝牙音乐互斥默认开启：无线连接时尝试释放本次目标手机的 A2DP 媒体连接，保留蓝牙通话和配对；系统接口不可用或未确认成功时提供手动说明。若点击播放立即暂停，在手机的车机蓝牙设备详情中关闭“媒体音频”、保留“通话音频”，重新连接后测试。不要通过关闭全部蓝牙排查无线交接。

标准方向盘媒体键与语音键按真实会话转发；实际按键分发、Siri 双向声音和原车焦点竞争仍需对应 L7 固件验证。

方控偶发无效或延迟时，打开「设置 → 调试 → 方控调试」。出现问题后点击「标记刚才方控失效」，正常时可标记对照；页面显示输入、过滤、蓝牙等待、手机排队与通道写入的阶段和耗时。查看日志时搜索 `STEERING_TRACE`，用 trace 编号对应同一次操作；手机状态单独记录，写入成功不等于手机已执行。「清空本页记录」保留已有日志，日志需主动查看、复制或上传。

打开「设置 → 调试 → 语音输入测试」，按三个步骤操作：先授权麦克风，再点「开始测试（10 秒）」并对车机说一句话，观察输入电平和采集时间；默认常规语音输入，也可切换麦克风原始输入或通话语音输入对照。不保存录音，离页／后台停止，回到前台不续录。第三步连接手机后发起 Siri，等手机打开语音输入再说话，按实际情况记录「手机有响应／无响应或识别异常」。请求发出不等于手机识别；记录绑定本次请求和手机会话，重连后重新测试。技术计数、设备类型、系统静音与原始错误在「查看技术明细」中展开，完整日志始终保存；搜索 `VOICE_TEST`、`VOICE_SIRI phase=USER_OBSERVATION`、`VOICE_UPLINK`。授权后不会自动录音；当前连接未启用麦克风时先重新连接。

硬件解码调用检查位于「设置 → 调试 → 硬件解码测试」。先结束手机连接，选择 H.264／HEVC、硬件解码器与调用方式，再把预览区域滚动到屏幕内，点「开始所选方式」观察两秒动态色块。可依次运行全部五种方式；若要逐项记录画面，请分别运行，每次完成后选「我看到了动态画面」或「无画面或画面异常」，判断绑定最后一次运行和视频格式。创建或输出成功不能代替实际画面判断。

默认只列硬件视频解码器；没有硬件候选时可主动开启软件对照，软件成功不计硬件通过。libopus 属于软件音频编解码，不列入本页硬件测试。固定样例为 640×360、30 fps，不代表实际投屏分辨率、60 fps、传输延迟或长时稳定性已通过。离页、后台、请求连接或超时停止，回到前台不续跑；无法确认测试进程退出时阻止新测试，退出并重新打开应用再排查。技术明细默认折叠，摘要和人工判断均进入原日志队列，可在日志页面手动上传，搜索 `CODEC_PROBE`。

## 认证来源

连接方式与认证来源分别配置：USB 有线 CarPlay 不等于 USB 认证模块。

| 来源 | 使用方法 |
| --- | --- |
| 应用内置（默认） | 使用构建时的本地认证输入；源码验证包不包含此身份 |
| 文字快捷导入 | 在认证设置粘贴配套私钥与证书，校验通过后保存到本机 |
| USB CH341 | 连接受支持模块并授予 USB 权限，选择对应来源 |
| Remote MFi | 填写服务地址与独立令牌；保存格式通过不代表远程认证连接成功 |

文字导入接受 PKCS#8 `PRIVATE KEY` PEM 或 Base64 私钥，证书接受 PKCS#7 或 `CERTIFICATE` PEM / Base64。要求 P-256 私钥和证书匹配；不支持加密私钥、`EC PRIVATE KEY` 或多个独立证书块。每个输入最多 32 KiB，解码后最多 16 KiB。失败保留旧材料；成功结束旧会话，需从连接页重新连接。

远程地址不包含内嵌账号密码、查询参数或片段，令牌单独填写。显式选择 USB 或远程来源后，内置材料不会覆盖选择。输入、令牌和本地材料不参与日志、界面状态备份或 Git 提交。

## 诊断与排障

设置 → 调试提供基础环境与权限检查。进入页面只读取本地历史，点击「收集环境与调试信息」或「重新收集环境与调试信息」才查询当前应用身份、系统、窗口、可见库/包、音频/网络/USB、调试配置与会话状态，以及权限定义、声明、授予和 AppOps。每次主动收集生成新批次，逐项事实同时进入脱敏日志队列并落盘；报告用于展示，清空报告保留已有日志。所有这些日志可在「设置 → 日志」查看、导出或主动上传。采集不请求权限、不启动连接、不执行 Hook 或向手机发送命令；同意首次使用协议后即可使用，无需悬浮窗授权。

收集开始后显示进度弹窗，展示检查数量与当前项目；停止操作只在弹窗内。点「停止收集」保留已完成的信息，等待当前查询结束时可直接关闭；返回或右上角关闭需确认「终止并关闭」。完成后点击「查看检查结果」进入表格，不自动跳转。进入后台会停止后续收集。

首页快捷操作依次为「查看日志、上传日志、清空日志、清空报告」，每项独占一行。日志查看器支持普通文本搜索、高亮匹配、复制全部或筛选结果，长按可复制单行；刷新保留搜索词。内容过长时按系统剪贴板容量分段选择复制，不静默截断。查看器读取与上传相同的有界脱敏快照，查看和复制不发送网络请求。

清空操作均需确认：清空日志会取消当前上传并清除应用内运行、采集和内存日志，活动会话随后仍可记录新内容；清空报告仅删除本地检查历史，保留日志；两种清空都会停止当前上传并丢弃旧重试快照，清空期间不能新建上传。已导出的下载目录文件不受影响。采集未结束时需先停止并等待结束，才能清空。

结果默认在同一张紧凑表格展示全部项目，列为项目、状态、原因；绿勾表示检查通过或已授权，灰色表示无权限、待验证或未执行，黄色表示异常，红色仅表示有明确证据不支持。保留状态筛选与权限原名搜索，点击行查看完整原因和证据并单独复查；重新收集后恢复全部结果。权限获授不等于接口可调用；“定义不可见”不能当成系统不支持。停止、离开调试范围、进入后台、退出或撤回协议后停止调度并保留部分结果；系统查询尚未返回时显示等待，不启动第二个工作线程。主题与页面布局刷新不重启检查。

完整 JSON 检查报告保留最近 10 批、每批最多 2 MiB、合计最多 20 MiB；进程中断的批次标记为中断，不自动续跑。表格上方「报告操作」可复制摘要、导出 JSON 至 Downloads/GalaxyPlay 或自选位置，删除前确认。历史结果不能代替当前环境检查。

每次手动收集将批次、时间、当前配置、各项结论与必要证据写入日志，完成后显示批次号。采集日志独立保留最近两批，每批最多 512 KiB，超限标记截断；日志查看、文本导出与手动 OpenObserve 上传包含这些记录。上传优先保留环境与权限记录，再纳入最近的运行日志，按每次 1 MiB 请求正文预算整理，超限丢弃较旧记录并显示数量。原始硬件编号、凭据和静态来源清单不写入日志；完整 JSON 不会作为附件自动上传。删除 JSON 报告不会删除已经写入的日志。

悬浮日志默认关闭，在「日志与报告」用同一个开关显示或关闭；权限不足先引导授权，取消或启动失败保持关闭，服务实际显示后才更新为开启。从浮窗内关闭或系统撤销权限后，设置开关同步回到关闭；不影响 CarPlay 连接。运行日志由用户主动导出，可在「日志与报告」指定保存位置或使用默认 Downloads/DiPlay 目录。分享前检查个人信息，只提供必要时间段和匿名现象。

### 媒体与 HUD 手动上报测试

先断开 CarPlay，在「设置 → 调试」进入「媒体上报测试」或「HUD 导航上报测试」，确认开始后才向服务发送测试数据；两项不能同时运行。媒体采用无声合成曲目，可手动切换 A／B、播放／暂停、进度增加 15 秒、封面 A／B／清空；播放可能切换原车媒体源，但不会控制手机或播放声音。HUD 仅发送已经核对的导航启停与测试路名，可切换和手动重新检查／重发；当前路名接口可能只缓存，完整导航显示仍需核对字段与实车结果，不发送猜测的距离／ETA／转向。

可返回或切到原车界面查看媒体卡片、HUD／仪表，再回到测试页对照当前曲目、播放状态、进度、封面或路名，记录「显示与样例一致」或「未显示或与样例不符」。更新样例会清除上一条页面判断，新结果绑定当前样例；旧结果仍在日志中。开始前不显示无效操作，服务异常以可读提示展示，具体字段在「查看技术明细」展开。接口结果和手动观察分别进入默认脱敏日志；从本页「查看与上传测试日志」进入日志页，由用户主动上传。测试最长两分钟；「结束上报并注销」、发起真实连接、撤回协议或退出时停止并清理。结束后使用「测试信息已清除／仍有残留或异常」单独记录原车清除结果；本地释放、接口返回和实际显示不是同一个结果。服务缺失或拒绝会保留具体阶段及异常类型，不显示成上报成功。

### 手动上传到 OpenObserve

设置 → 日志 → OpenObserve 日志服务器，填写完整写入地址及 Authorization 值（包含 `Basic ` 前缀）。地址可使用 `https://服务器/api/组织/{HeadUnit}-{DeviceID}/_json`：`HeadUnit` 来自车机厂商与型号，`DeviceID` 为本机设备哈希；也支持仅 `{DeviceID}` 或控制台的普通示例地址。应用保留服务器和组织，上传时替换流名，打包内置地址在列表和弹窗显示为 `*****`；已有认证信息也不填入输入框。隐藏字段留空保留原配置，不修改直接保存不会生成覆盖值；更换服务器地址需重新填写认证。默认值可由打包配置提供，应用内保存的配置优先；「恢复打包默认值」清除覆盖值。配置和打开页面均不会发送日志。

点击「上传日志」才发送日志快照：每次最多 1 MiB（1,048,576 字节，包含 UTF-8 JSON 元数据），分为每批不超过 256 KiB 的请求，最多保留 5000 条日志，另附快照与整理摘要。无可上传内容时显示「暂无可上传日志」，不发送请求、不更新上次成功记录；请先收集环境与调试信息或复现问题。上传期间用进度弹窗显示批次、记录与超限省略数量，可直接停止。失败在同一弹窗给出原因及「重试上传／关闭」，页面没有独立重试入口；再次点击上传会先显示尚未处理的失败提示。重试需明确点击并跳过已确认批次，成功后保留日志名称供反馈。返回或关闭进行中的任务需确认终止；进入后台会停止上传，返回不自动续传。遮盖凭据、地址、个人标识和原始载荷，保留 codec、分辨率、音频 usage/焦点/BUS、权限原名、错误码与计时等技术信息；不上传完整 JSON 设备报告、认证材料、声音或图片。撤回协议、退出应用或修改服务器会取消当前任务，已经到达服务端的记录不能因此撤回。若超时或部分写入后重试，OpenObserve 可能保存重复记录，可按 `event_id` 识别；应用不会自动重试。如果提示「日志流正在删除中（HTTP 400）」，需等待 OpenObserve 完成远端删除任务后重试，持续出现时检查服务器；本地清空不会删除远端日志流。

诊断页的「日志名称」显示服务端实际使用的名称，点击可复制，上传成功提示也会显示；OpenObserve 会将名称中的连字符规范化为下划线。每台车上传到独立的同名日志流，正文不包含 `device_id`；反馈问题时提供日志名称。设备哈希优先基于 Android ID 生成，不包含原始 Android ID 或序列号；同一设备、用户与签名环境下保持稳定，恢复出厂、更换签名或随机回退后清除数据可能改变哈希。

页面上传状态显示「未上传」，或「已上传」并列出上次成功时间和日志条数。只在全部批次获服务器确认后保存，重启应用仍保留；失败、取消及修改服务器不覆盖上次成功记录。条数包含上传整理摘要，部分批次成功仍属于未完成上传。旧版没有保存的上传时间不会补记。

在 OpenObserve 直接选择与应用显示名称一致的日志流，再用 `report_id` 筛选本次报告并按 `line_index` 排序。`message` 为日志正文，`app_version` / `core_version` 为版本，`collected_at` 为车机整理时间；查询时间默认按服务端接收时间，日志行内仍保留原时间。服务器及其代理可以看到来源 IP。车辆热点不保证可访问互联网，失败时仍可本地导出后再处理。
