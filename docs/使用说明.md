# 使用说明

[下载安装](https://car.tamshen.com/apps/com-ecarx-carplay/) · [首次连接](#连接) · [常用设置](#菜单与设置) · [遇到问题](#诊断与排障) · [反馈显示问题](#媒体与-hud-手动上报测试)

Galaxy Play 用于吉利银河 L6／L7 车机，最低支持 Android 10。请停车后安装和操作。

## 安装与首次启动

1. 在车机安装 APK。已有 Galaxy Play 可直接覆盖更新，保留设置；提示签名冲突时先反馈，避免卸载丢失配置。
2. 打开应用，阅读协议到底，等待倒计时结束后勾选同意。
3. 按提示授予蓝牙、麦克风等权限。只有需要桌面悬浮入口时才授予悬浮权限。
4. 打开「设置 → 偏好设置 → 配置文件」，选择对应的 L7 带头枕、L7 无头枕或银河 L6 模板，点击「基于此配置新建」，检查后点击「新建配置文件」并命名保存。

首次使用先保留模板默认参数，再选择下面一种方式连接。

## 连接

### 无线：原生热点

打开「连接 → 无线连接」，连接方式选择「原生热点」。

1. 在车机系统中配对 iPhone 蓝牙，保持手机 Wi-Fi 和蓝牙开启，在应用中选中这台手机。
2. 点击「一键开启原生热点」。需要授权时按提示处理，再返回重试。
3. 读取并核对热点名称、密码；读不到时，从 Android 原生热点设置查看并手动填写。
4. 让 iPhone 加入这个热点，点击「无线连接」，按手机提示允许 CarPlay。

这里使用 **Android 原生热点**，与车机桌面自带热点服务可能不同。手动填写名称和密码只保存连接信息；需要修改系统热点时，按「生成 CarPlay 热点配置」的提示确认应用。

### 无线：Wi-Fi Direct

打开「连接 → 无线连接」，将「无线连接方式」改为「Wi-Fi Direct」。

1. 开启车机 Wi-Fi，选择已配对的 iPhone。
2. 保持 iPhone Wi-Fi、蓝牙开启，无需填写热点名称和密码。
3. 点击「无线连接」，按提示允许 CarPlay，等待手机接入。

等待接入最多约 30 秒，期间先观察页面阶段。失败后按提示重试，避免连续点击断开、重连。地区选择实际使用地区，频道先用页面默认值。

### USB 有线

打开「连接 → 有线连接」。

1. 用支持数据传输的线，将 iPhone 接到车机数据口。
2. 解锁 iPhone，开始连接，处理车机的 USB 和网络授权提示。
3. 在 iPhone 上允许信任及 CarPlay，等待投屏画面。

只有充电、检测不到设备时，先换数据线或数据口。网络授权失败时按错误弹窗操作，可选择「重新检查并授权」。

0.1.167 起可在有线页的「USB 连接方式」选择「USB连接验证测试」并保存，再开始连接。默认仍为标准 USB；更改前先断开当前连接。实验方式检查车机已有能力后尝试角色切换，使用系统 USB 网络，不弹 VPN 网络授权。它依赖固件规则和控制接口，尚未完成实车验收。

复测时保留当前认证设置，解锁 iPhone 后进行一次连接；若失败，记录屏幕原因码并通过「设置 → 日志」主动上传。不要连续反复点击连接。出现恢复提示时，先取消连接、拔出 iPhone 数据线，在有线页点「恢复 USB 原配置」，确认完成后重新插线。实车复测分别记录首次连接、取消后再次连接、拔线重插以及实际画面、触控和声音，不能用“配置成功”代替投屏成功。

**看到 CarPlay 画面后再检查触控和声音。** 需要重连时点击左侧「重连」并确认；仍在等待连接时，可点击「取消连接」结束。

## 菜单与设置

点击投屏上的悬浮图标可展开菜单；「画面」回到 CarPlay，「车机」返回原车界面，「退出」结束连接并关闭应用。

| 想做什么 | 去哪里 |
| --- | --- |
| 调清晰度、流畅度、音乐缓冲 | 设置 → 偏好设置 → 常用 |
| 调画面比例、系统栏、解码器 | 设置 → 偏好设置 → 画面 |
| 调音乐、导航、Siri、通话声音 | 设置 → 偏好设置 → 音频 |
| 开关原车媒体注册和导航上报 | 设置 → 偏好设置 → 上报 |
| 改连接方式、热点、自动连接 | 设置 → 连接设置 |
| 改语言、界面大小、昼夜显示、悬浮菜单 | 设置 → 应用设置 |
| 改 CarPlay 的「回到车机」名称或图标 | 设置 → 应用设置 → CarPlay 返回入口 |
| 更新应用 | 设置 → 关于 → 检查更新 |

**偏好设置改完要保存，再重新连接生效。** 应用设置和连接设置在各自页面确认保存。

原车音乐与媒体上报只有一个开关，默认开启，以 Galaxy Play 身份注册；关闭后不注册。歌名、封面和播放状态能否显示，仍需在实车确认。

### 保存与分享配置

- **修改当前配置：** 调整参数后点击「保存」；「撤销修改」放弃未保存内容。
- **保留另一套参数：** 在配置文件列表点击「复制为新文件」，检查后命名保存。
- **分享给别人：** 点击「分享」，可填写备注，再发送二维码或复制文本。分享会包含当前未保存的参数。
- **使用别人配置：** 点击「导入」，粘贴配置文本，核对预览后确认。二维码先用手机识别并复制文字。

切换配置前先保存草稿。配置文件不包含热点密码、手机配对或认证材料；「重置」前请核对弹窗说明的范围。

## 音频与蓝牙

音乐输出在 iPhone 上选择 CarPlay，原车媒体来源选择 GalaxyPlay。

需要调整声音时，打开「偏好设置 → 音频」，选择音乐、导航、Siri 或通话，先试听，再确认、保存并重连。有头枕音响时，同时检查原车头枕模式，按实际听到的位置判断。

音乐一播放就暂停时，先检查「偏好设置 → 常用 → 蓝牙音乐互斥」。若仍异常，在蓝牙设备设置中关闭这台 iPhone 的「媒体音频」，保留通话和蓝牙配对，再重新连接。

音乐卡顿可尝试提高音乐缓冲；缓冲越大，声音延迟越明显。电话和 Siri 先保持默认值。

## 诊断与排障

| 遇到的现象 | 先做这一步 |
| --- | --- |
| 无线一直连不上 | 核对所选手机、蓝牙和 Wi-Fi；原生热点方式还要确认手机已加入正确热点。记下等待页停在哪一步 |
| USB 只有充电 | 换数据线、数据口，解锁手机并检查 USB／信任提示 |
| 黑屏但有声音 | 有「重试画面」时先点击；仍失败则在偏好设置 → 画面关闭 HEVC，保存后重连 |
| 音乐暂停、无声或声音位置不对 | 按上面的音频与蓝牙步骤处理，音乐、导航、Siri、通话分别试听 |
| 仪表歌名、封面不更新 | 先确认媒体上报开关已开启并重连，再按下方步骤记录实际显示 |
| 找不到桌面悬浮入口 | 检查应用设置中的车机桌面悬浮菜单开关及系统悬浮权限；应用在前台时桌面入口会隐藏 |
| 提示缺少认证 | 打开应用设置 → CarPlay 认证，核对来源；内置认证包默认选择「应用内置」 |

不确定从哪里查时，打开「设置 → 调试 → 开始完整调试」，按页面提示操作和记录结果。

### 媒体与 HUD 手动上报测试

**真实播放时记录仪表问题：**

1. 连接 iPhone 并播放音乐，确认手机上的歌名、封面和播放状态。
2. 打开「设置 → 调试 → 单项与高级调试 → 媒体上报测试」。
3. 分别点击「记录中控显示」「记录仪表显示」，逐项填写正确、未显示、未更新或错误。
4. 发生切歌、暂停或重连后重新观察，再记录本次结果。
5. 到「设置 → 日志」上传，并提供下面的反馈信息。

**需要用样例单独测试时：** 先断开 CarPlay，在「媒体上报测试」或「HUD 导航上报测试」开始测试，切换曲目／封面或导航样例，到原车界面观察后回来记录。结束时点击「结束上报并清理」，再确认原车是否清除了测试内容。每次最长两分钟，两项分别测试。

注册成功只说明服务接入结果；显示是否正常，以中控和仪表实际观察为准。

### 上传日志和反馈

1. 复现问题后，打开「设置 → 日志 → 上传日志」。
2. 备注写清操作和现象，例如「切下一首后，中控已更新，仪表仍显示上一首」。
3. 点击「开始上传」，等待显示成功。失败时可在弹窗中重试，或导出日志。
4. 复制上传记录，连同下面的信息一起反馈。

```text
应用版本：
连接方式：原生热点／Wi-Fi Direct／USB
做了什么：
实际结果：中控、仪表分别怎样
大约发生时间：
上传记录：日志名称、报告编号
```

日志由你主动上传。内置服务器已配置时可直接使用；需要更换服务器才进入「日志 → OpenObserve 日志服务器」，按维护者提供的信息填写。反馈中不要附上密码、令牌或认证材料。

## 认证来源

日常使用内置认证包，保持「应用内置」即可。需要文字导入、USB CH341 或 Remote MFi 时，从「设置 → 应用设置 → CarPlay 认证」选择，按页面要求填写并确认；更换后重新连接。

USB 有线连接与 USB 认证模块是两个独立选项，使用数据线连接手机不需要因此切换认证来源。
