# 使用说明

[项目入口](../README.md) · [开发与验证](开发与验证.md)

## 安装与首次启动

仅面向吉利银河 L7，最低 Android 10，目标环境为 Flyme OS / Android 11、1440×1920 竖屏。应用包名为 `com.ecarx.carplay`。覆盖安装需要签名一致、版本码符合系统要求；同名原厂应用不一定能被本项目覆盖。

首次使用或协议正文变更后，必须滚动至文末、在前台等待至少 5 秒，再主动勾选并同意。计时未完成时转到后台，返回后重新计时。拒绝则退出；未同意时不启动连接。设置 → 关于 → 使用协议可查看或撤回；撤回停止会话和服务、清除同意记录，保留连接配置。

麦克风、蓝牙及连接相关权限按用途申请。系统悬浮权限用于桌面菜单和可选调试日志，不是 CarPlay 连接条件。从系统设置返回后，以应用重新查询的权限结果为准。

## 连接

| 方式 | 操作 |
| --- | --- |
| 无线 | 在车机系统开启原生热点，让 iPhone 加入；在应用连接设置填写热点信息并选择手机，按提示完成蓝牙授权，然后启动无线连接 |
| USB 有线 | 使用支持数据传输的线连接 iPhone，在首页选择有线连接，并处理设备授权 |
| 立即连接 | 完成配置后显示，沿用上次连接方式；已有任务时查看进度或返回 CarPlay，不重复建会话 |

应用不自动创建、更改或关闭车机热点。填写热点名称和密码只保存应用配置。等待页的返回保留连接任务，取消结束本次任务。切换设置、返回桌面或关闭悬浮日志不会断开连接。

HEVC 尚未完成实车验收，默认使用 H.264 / 30 fps。出现黑屏但有声音时，在显示设置关闭 HEVC 后重新连接，并导出对应时段诊断；有声音不能证明视频解码成功。

## 菜单与设置

一级菜单只有画面、设置、车机、退出。首页和连接成功后默认收起为可拖动图标；点击图标或投屏页返回键，在左上角固定位置展开。点击画面或菜单外收起，不改变投屏画布。退出需确认，随后停止连接及服务并结束应用进程。

设置包含认证、连接、显示、音频、通用、权限、调试、关于八类。调试是设置首页独立入口，日志归入调试；调试子页返回调试首页，再返回设置。其他分类子页返回设置首页，再次点击侧栏设置始终回到分类首页；从画面返回设置可恢复原子页。选择器确认才保存，取消或系统返回保留旧值；需重建会话的参数下次连接生效。

| 常用功能 | 位置与说明 |
| --- | --- |
| 界面大小 | 显示 → 应用界面；小 240、中 280（默认）、大 320 DPI，或自定义 160～480；只调整应用 UI，不改系统密度和投屏参数 |
| 悬浮入口 | 显示 → 悬浮菜单；调整透明度、桌面悬浮菜单开关，位置可拖动保存 |
| 桌面快速返回 | 同意协议且授予悬浮权限后启用；退到桌面显示同套菜单，画面返回已有会话或首页，不自动连接 |
| 投屏参数 | 显示 → 投屏画面；全屏、编码与帧率等按实际设备能力设置 |
| 自动连接 | 通用设置；仍受首次使用协议与权限检查约束 |
| 应用语言 | 通用 → 应用语言；保留简体中文、English 和跟随系统，升级后已移除的语言选择回到跟随系统 |
| 开源项目 | 关于；DiPlay 与吉利二改参考分别列出版本，点击项目以模态框显示 URL、说明及打开链接按钮；第三方许可单独离线阅读 |
| 调试 | 设置 → 调试；主动运行基础检查、筛选结果、单项复查和查看历史报告 |
| 日志与报告 | 设置 → 调试 → 日志与报告；查看、复制、导出、悬浮日志和远程日志集中在此 |

## 音频与蓝牙

音频设置分别提供媒体音乐、语音助手、导航播报，默认对齐 DiPlay 原版 0.2.11 的系统用途。电话通道独立管理。每项可以选择其他标准用途或高级传统音频流；传统编号不是物理扬声器编号。覆盖升级保留已有选择；单项选“内置推荐”可恢复该用途，点击“恢复原版默认音频”并确认可一次恢复全部音频默认值，下次连接生效。配对、认证与蓝牙媒体交接设置保留。

音频焦点默认关闭；即使开启，导航也不申请焦点，Siri 使用可降音的临时焦点，焦点丢失或申请失败时不由本应用强制静音。“尝试 L7 BUS 路由”默认关闭，播放和录音由系统选择设备；确需指定厂商路径时再开启并实车验证。

先选策略，再点击两秒试听，必要时立即停止；试听不保存，确认后才保存，取消保留旧值。修改在下次连接生效。输出设备信息和播放调用成功不等于实车已发声，需分别确认音乐、导航、Siri 与通话。

音频 → 播放与焦点提供「通话回声消除与降噪」，默认开启，仅通话录音使用系统支持的 AEC/NS，Siri 录音不启用该处理。若升级后通话回声、音量或路由变差，可关闭后重新连接对比。原车处于通话、响铃或通信模式时不主动覆盖其模式。

蓝牙音乐互斥默认开启：无线连接时尝试释放本次目标手机的 A2DP 媒体连接，保留蓝牙通话和配对；系统接口不可用或未确认成功时提供手动说明。若点击播放立即暂停，在手机的车机蓝牙设备详情中关闭“媒体音频”、保留“通话音频”，重新连接后测试。不要通过关闭全部蓝牙排查无线交接。

标准方向盘媒体键与语音键按真实会话转发；实际按键分发、Siri 双向声音和原车焦点竞争仍需对应 L7 固件验证。

## 认证来源

连接方式与认证来源分别配置：USB 有线 CarPlay 不等于 USB 认证模块。

| 来源 | 使用方法 |
| --- | --- |
| 应用内置（默认） | 使用构建时的本地认证输入；源码验证包不包含此身份 |
| 文字快捷导入 | 在认证设置粘贴配套私钥与证书，校验通过后保存到本机 |
| USB CH341 | 连接受支持模块并授予 USB 权限，选择对应来源 |
| Remote MFi | 填写服务地址与独立令牌；保存格式通过不代表远程认证连接成功 |

文字导入接受 PKCS#8 `PRIVATE KEY` PEM 或 Base64 私钥，证书接受 PKCS#7 或 `CERTIFICATE` PEM / Base64。要求 P-256 私钥和证书匹配；不支持加密私钥、`EC PRIVATE KEY` 或多个独立证书块。每个输入最多 32 KiB，解码后最多 16 KiB。失败保留旧材料；成功结束旧会话，需从连接页重新连接。

远程地址不包含内嵌账号密码、查询参数或片段，令牌单独填写。显式选择 USB 或远程来源后，内置材料不会覆盖选择。输入、令牌和本地材料不参与日志、界面状态备份或 Git 提交。

## 诊断与排障

设置 → 调试提供基础环境与权限检查。进入页面只读取本地历史，点击「收集环境与调试信息」或「重新收集环境与调试信息」才查询当前应用身份、系统、窗口、可见库/包、音频/网络/USB、调试配置与会话状态，以及权限定义、声明、授予和 AppOps。每次主动收集生成新批次并写入脱敏日志，不请求权限、不启动连接、不执行 Hook 或向手机发送命令；同意首次使用协议后即可使用，无需悬浮窗授权。

结果默认在同一张紧凑表格展示全部项目，列为项目、状态、原因；绿勾表示检查通过或已授权，灰色表示无权限、待验证或未执行，黄色表示异常，红色仅表示有明确证据不支持。保留状态筛选与权限原名搜索，点击行查看完整原因和证据并单独复查；重新收集后恢复全部结果。权限获授不等于接口可调用；“定义不可见”不能当成系统不支持。停止、离开调试范围、进入后台、退出或撤回协议后停止调度并保留部分结果；系统查询尚未返回时显示等待，不启动第二个工作线程。主题与页面布局刷新不重启检查。

完整 JSON 检查报告保留最近 10 批、每批最多 2 MiB、合计最多 20 MiB；进程中断的批次标记为中断，不自动续跑。表格上方「报告操作」可复制摘要、导出 JSON 至 Downloads/L7CarPlay 或自选位置，删除前确认。历史结果不能代替当前环境检查。

每次手动收集将批次、时间、当前配置、各项结论与必要证据写入日志，完成后显示批次号。采集日志独立保留最近两批，每批最多 80 KiB，超限标记截断；日志查看、文本导出与手动 OpenObserve 上传包含这些记录。上传优先保留环境与权限记录，再纳入最近的运行日志，总计不超过 1000 条和 256 KiB。原始硬件编号、凭据和静态来源清单不写入日志；完整 JSON 不会作为附件自动上传。删除 JSON 报告不会删除已经写入的日志。

悬浮日志默认关闭，用户主动开启并授予权限后可随时查看；关闭窗口保留连接。运行日志由用户主动导出，可在「日志与报告」指定保存位置或使用默认 Downloads/DiPlay 目录。分享前检查个人信息，只提供必要时间段和匿名现象。

### 手动上传到 OpenObserve

设置 → 调试 → 日志与报告 → OpenObserve 日志服务器，填写完整写入地址及 Authorization 值（包含 `Basic ` 前缀）。地址可使用 `https://服务器/api/组织/{HeadUnit}-{DeviceID}/_json`：`HeadUnit` 来自车机厂商与型号，`DeviceID` 为本机设备哈希；也支持仅 `{DeviceID}` 或控制台的普通示例地址。应用保留服务器和组织，上传时替换流名，页面显示实际写入地址。默认值可由打包配置提供，应用内保存的配置优先；「恢复打包默认值」清除覆盖值。配置和打开页面均不会发送日志。

点击「上传日志」才发送最近最多 1000 条、合计不超过 256 KiB 的脱敏文本；不上传完整设备报告、认证材料、声音或图片。页面显示成功、失败及取消状态；失败后可以手动重试。撤回协议、退出应用或修改服务器会取消当前任务，已经到达服务端的记录不能因此撤回。若超时或部分写入后重试，OpenObserve 可能保存重复记录，可按 `event_id` 识别；应用不会自动重试。

诊断页的「日志名称」显示服务端实际使用的名称，点击可复制，上传成功提示也会显示；OpenObserve 会将名称中的连字符规范化为下划线。每台车上传到独立的同名日志流，正文不包含 `device_id`；反馈问题时提供日志名称。设备哈希优先基于 Android ID 生成，不包含原始 Android ID 或序列号；同一设备、用户与签名环境下保持稳定，恢复出厂、更换签名或随机回退后清除数据可能改变哈希。

在 OpenObserve 直接选择与应用显示名称一致的日志流，再用 `report_id` 筛选本次报告并按 `line_index` 排序。`message` 为日志正文，`app_version` / `core_version` 为版本，`collected_at` 为车机整理时间；查询时间默认按服务端接收时间，日志行内仍保留原时间。服务器及其代理可以看到来源 IP。车辆热点不保证可访问互联网，失败时仍可本地导出后再处理。

| 现象 | 排查 |
| --- | --- |
| 无线未进入投屏 | 核对车机热点、手机加入状态、应用保存信息、蓝牙和认证来源，区分等待手机、认证与首帧阶段 |
| 提示缺少内置认证 | 使用带本地输入的构建，或文字导入 / 选择外部认证；无需先卸载或修改热点 |
| 黑屏但音乐正常 | 关闭 HEVC、使用 H.264 后重连，保留视频阶段诊断 |
| 音乐自动暂停或无声 | 检查蓝牙媒体互斥、播放策略与焦点结果，分别试听三用途 |
| 桌面无悬浮入口 | 核对显示设置开关、悬浮权限和协议状态；应用前台时桌面悬浮窗会隐藏 |

日志不替代实车听感和画面观察。不要公开密钥、配对信息、车辆或手机标识及原始诊断报告。
