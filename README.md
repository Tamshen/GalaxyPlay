# GalaxyPlay

**面向竖屏安卓车机的 CarPlay 接收端**

[![竖屏车机](https://img.shields.io/badge/Head_Unit-1440%C3%971920-2563EB?style=flat-square)](docs/使用说明.md)
[![Android 10+](https://img.shields.io/badge/Android-10%2B-3DDC84?style=flat-square&logo=android&logoColor=white)](docs/使用说明.md)


Galaxy Play 基于 [DiPlay](https://github.com/shihabal3amri/DiPlay)，差异化点是 **竖屏车机环境的专用适配**。

## 第三方组件与说明

- [DiPlay](https://github.com/shihabal3amri/DiPlay)  fork
- [xcertplay](https://github.com/shilapi/xcertplay) 上游核心

项目与 Apple 或任何汽车厂商、系统供应商均无隶属或背书关系。
